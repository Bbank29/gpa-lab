# โปรแกรมทดลองคำนวณเกรดเฉลี่ยสะสม (GPA)

เว็บสำหรับนักศึกษามหาวิทยาลัยสวนดุสิต ลองใส่เกรดที่คาดว่าจะได้ แล้วดู GPA ใหม่ทันที
มีแบบประเมินความพึงพอใจ และระบบผู้ดูแล (ซุปเปอร์แอดมิน / แอดมินทั่วไป) ที่เก็บข้อมูลในฐานข้อมูล SQLite

## โครงสร้างไฟล์

```
gpa-lab/
├── index.html                  หน้าเว็บ
├── setup.php                   ติดตั้งครั้งแรก / ตั้งรหัสซุปเปอร์แอดมินใหม่ (รันใน Terminal)
├── INSTALL.md                  คู่มือติดตั้งและตั้งค่า
├── .htaccess                   ให้เบราว์เซอร์โหลดโค้ดใหม่ทุกครั้งที่แก้ (รีเฟรชธรรมดาก็เห็น)
├── css/style.css               หน้าตาทั้งหมด (สี ขนาด มือถือ)
├── js/app.js                   การทำงานทั้งหมด (คำนวณ GPA, แบบประเมิน, หน้าแอดมิน)
├── js/excel.js                 สร้างไฟล์ Excel แบบประเมิน (ปุ่ม "ดาวน์โหลด Excel" ในหน้าแอดมิน)
├── images/                     แบนเนอร์ และภาพอธิบาย CAX/CGX
├── api/                        ส่วนเซิร์ฟเวอร์ (PHP) เชื่อมฐานข้อมูล
│   ├── common.php              เปิดฐานข้อมูล, สร้างตาราง
│   ├── auth.php                เข้าสู่ระบบ / ออกจากระบบ
│   ├── feedback.php            บันทึกและอ่านแบบประเมิน
│   └── admins.php              จัดการแอดมิน (เฉพาะซุปเปอร์แอดมิน)
├── database/
│   ├── schema.sqlite.sql       โครงสร้างตาราง (SQLite) ที่ระบบใช้จริง
│   └── gpa_lab.sql             โครงสร้างแบบ MySQL (สำรองไว้ ยังไม่ได้ใช้)
└── data/gpa_lab.db             ไฟล์ฐานข้อมูล (สร้างด้วย setup.php ไม่ขึ้น GitHub)
```

## ฐานข้อมูล

ใช้ **SQLite** เป็นไฟล์เดียวคือ `data/gpa_lab.db` เปิดดูได้ด้วยโปรแกรม **DB Browser for SQLite**
(File → Open Database → เลือก `data/gpa_lab.db` → แท็บ Browse Data)

| ตาราง | ช่อง | เก็บอะไร |
|---|---|---|
| `admins` | id, username, password_hash, display_name, role, created_at | บัญชีผู้ดูแล / role = `super` หรือ `admin` / รหัสผ่านเก็บแบบเข้ารหัส (bcrypt) |
| `feedback` | id, stars, comment, created_at | แบบประเมิน 1 แถวต่อการส่ง 1 ครั้ง / ดาว 1–5 / ความคิดเห็น (เว้นว่างได้) / วันเวลา |

- สร้างฐานข้อมูลและบัญชีซุปเปอร์แอดมินด้วย `php setup.php` ไม่มีรหัสเริ่มต้นในโค้ด
- ไม่เก็บชื่อหรือเกรดของนักศึกษาที่มาใช้
- จำนวนผู้ใช้ (นับคนเข้าเว็บ) นับที่บริการ abacus ไม่ได้อยู่ในฐานข้อมูล

## สิทธิ์แอดมิน

| | ซุปเปอร์แอดมิน | แอดมินทั่วไป |
|---|---|---|
| แดชบอร์ด, ความคิดเห็น | ✅ | ✅ |
| ดาวน์โหลดแบบประเมินเป็น Excel | ✅ | ✅ |
| เพิ่ม / ลบแอดมินทั่วไป (ไม่จำกัดจำนวน) | ✅ | ❌ |
| แก้ชื่อ / ตั้งรหัสใหม่ให้แอดมินทั่วไป | ✅ | ❌ |
| แก้ชื่อ / รหัสของตัวเอง | ✅ | ❌ ต้องให้ซุปเปอร์แอดมินแก้ให้ |

## ติดตั้งและตั้งค่า

ดูขั้นตอนทั้งหมดที่ **[INSTALL.md](INSTALL.md)** (เซิร์ฟเวอร์จริง, XAMPP, การตรวจหลังติดตั้ง, การสำรองข้อมูล)

## ขึ้น GitHub

ไฟล์ `.gitignore` ตั้งไว้แล้วว่า**ไม่อัปโหลด `data/gpa_lab.db`** (ข้อมูลจริงและรหัสผ่านไม่ควรอยู่บน GitHub)
คนที่ดาวน์โหลดไปใช้ต่อสร้างฐานข้อมูลใหม่ด้วย `php setup.php`

```bash
cd gpa-lab
git remote add origin https://github.com/<ชื่อบัญชี>/<ชื่อ repo>.git
git push -u origin main
```

แก้โค้ดแล้วส่งขึ้นใหม่: `git add .` → `git commit -m "แก้อะไร"` → `git push`

คนต่อไปที่นำไปใช้: ดาวน์โหลด (Code → Download ZIP หรือ `git clone`) แล้วทำตาม [INSTALL.md](INSTALL.md)

## เปิดแบบไฟล์เดียว (ไม่มีเซิร์ฟเวอร์)

ดับเบิลคลิก `index.html` หรือส่งไฟล์เดียว `gpa.html` ทางแชตก็ใช้คำนวณได้
แต่หน้าแอดมินจะเป็น**โหมดตัวอย่าง** (ข้อมูลอยู่ในเครื่องที่เปิดเท่านั้น ไม่ปลอดภัย ใช้นำเสนอ)
ถ้าต่อฐานข้อมูลได้ หน้าแอดมินจะมีแถบเขียวด้านล่าง ถ้าไม่มีแถบคือโหมดตัวอย่าง

## จะแก้อะไร ไปที่ไหน

| อยากแก้ | ไฟล์ |
|---|---|
| ข้อความเกณฑ์ผลการเรียน | `index.html` ส่วน "ป๊อปอัป: เกณฑ์ผลการเรียน" |
| ข้อความคำอธิบาย CAX / CGX | `js/app.js` ส่วนที่ 5 |
| สีประจำวิชา / ค่าเกรด | `js/app.js` ส่วนที่ 1 |
| หน้าแอดมิน | `index.html` ส่วน "แผงผู้ดูแล" และ `js/app.js` ส่วนที่ 8 |
| สิทธิ์และการบันทึกฐานข้อมูล | `api/*.php` |
| การสร้างบัญชีซุปเปอร์แอดมิน | `setup.php` |
| แบบประเมินเด้งเองเมื่อเห็นผลแล้วหยุดใช้งาน 15 วินาที (ตัวเลข `RATE_IDLE_MS`) | `js/app.js` ส่วนที่ 8.1 |
| หน้าตาไฟล์ Excel ที่ดาวน์โหลด (ชีต สี ความกว้างคอลัมน์) | `js/excel.js` |
| สีและขนาด | `css/style.css` |
